## 🛠️ Official SDKs

### Node.js/TypeScript
- **Repository**: [openai/openai-node](https://github.com/openai/openai-node)
- **NPM**: [@openai/realtime-api-beta](https://www.npmjs.com/package/@openai/realtime-api-beta)
- **Installation**: `npm install openai @openai/realtime-api-beta`

Key features:
- Full TypeScript support
- Realtime WebSocket client
- Automatic reconnection handling
- Event-based architecture

### Python
- **Repository**: [openai/openai-python](https://github.com/openai/openai-python)
- **PyPI**: [openai](https://pypi.org/project/openai/)
- **Installation**: `pip install openai`

Key features:
- Async/await support
- Type hints
- Comprehensive error handling
- Streaming responses
